## ⚙️ Installation

### 1. Clone the Repo

```bash
git clone https://github.com/starpig1129/DATATEX.git
cd DATATEX
```

### 2. Create Environment

```bash
conda create -n DATATEX python=3.10
conda activate DATATEX
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```
